# Parking Lot LLD Learning Project

This folder captures the Parking Lot LLD course phase-by-phase.

## Core design approach
Problem → requirements → use cases → domain objects → responsibilities → relationships → variation points → patterns → persistence → concurrency → performance → infrastructure.

Do not force patterns. Introduce them only when a concrete design pressure appears.
