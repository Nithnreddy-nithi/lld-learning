# LLD Learning Repository

A phase-by-phase low-level design learning repository focused on understanding **why** a design is chosen, not just copying class diagrams.

## Goals

- Learn a repeatable LLD approach for interviews and production design.
- Build one project at a time in clearly separated phases.
- Keep each phase readable, visual, and independently reviewable.
- Commit every completed phase separately so Git history becomes the learning timeline.

## Projects

### 1. Cricbuzz-like Live Cricket System

Path: [`projects/cricbuzz-like`](projects/cricbuzz-like)

Completed so far:

- Phase 01 — Requirements & System Boundaries
- Phase 02 — Actors, Use Cases & Candidate Domain Objects
- Phase 03 — Entities, Value Objects, Enums & Domain Services
- Phase 04 — Relationships, Ownership, Composition & Cardinality

## Commit convention

```text
learn(cricbuzz): complete phase 01 requirements and boundaries
learn(cricbuzz): complete phase 02 object discovery
learn(cricbuzz): complete phase 03 domain object classification
learn(cricbuzz): complete phase 04 relationships and ownership
```

Future projects will follow the same structure.
